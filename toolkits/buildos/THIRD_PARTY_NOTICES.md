# Third-Party Notices

This file holds the license notice of every piece of third-party code in the npm package `@brucewaynedecoy/buildos`. It ships in the package next to `SECURITY.md`, which lists the same code with its version, reason, and scan status, and the CycloneDX SBOM of each release lists it as components with scope `required`.

All of the code below is inside one file, the bundle `dist/buildos.js`, which esbuild builds. The bundle also carries these notices as esbuild legal comments. It holds:

- BuildOS code (Apache-2.0, see `LICENSE`).
- Unicode tables copied from the Go 1.24.1 standard library, and ports of Go standard library and `golang.org/x/net/html` code to TypeScript (BSD-3-Clause, one notice below). No Go code ships.
- A port of the first checks of the Go module `github.com/ledongthuc/pdf` (BSD-3-Clause).
- Four npm packages: `fflate` 0.8.3 (MIT), `parse5` 8.1.1 (MIT) with its dependency `entities` 9.0.0 (BSD-2-Clause), and `unpdf` 2.1.0 (MIT) with the pdf.js 6.4.299 build it contains (Apache-2.0).
- Six components that pdf.js inlines: the Brotli decoder, the OpenJPEG, JBIG2, and qcms decoder loaders, and the Emscripten and wasm-bindgen glue they were built with. Each has its own notice after pdf.js.

The package also carries project files that `buildos init` copies into a project (`dist/system/`). They are BuildOS files under the BuildOS license and hold no third-party code.

The build-time tools (TypeScript, esbuild, the Node type definitions, and their platform packages) are not bundled and do not ship, so they have no notice here; `SECURITY.md` lists them. Tests use Node's built-in test runner, `node:test`, so no test framework is installed or bundled. CI checks this file against the bundle, the lockfile, `SECURITY.md`, and the SBOM (`test/notices.test.ts`, `scripts/sbom.ts`).

## Go Standard Library: `strconv` Printable-Rune Tables

- What ships: the four printable-rune tables (`isPrint16`, `isNotPrint16`, `isPrint32`, and `isNotPrint32`) of the Go standard library, re-encoded as base-36 deltas in `src/core/shared/go-isprint.ts` and bundled into `dist/buildos.js`, and a port of the Go `strconv.IsPrint` lookup in `goIsPrint` (`src/core/shared/go-quote.ts`). BuildOS uses them so that its `strconv.Quote`-style escaping matches the Go CLI seed byte for byte.
- Source: Go 1.24.1 (Unicode 15.0.0). `scripts/generate-go-isprint.ts` reads `src/strconv/isprint.go` (itself generated by Go's `src/strconv/makeisprint.go`) and `src/unicode/tables.go` (for the Unicode version only). The lookup follows `IsPrint` and `bsearch` in `src/strconv/quote.go`. The license text below is the Go 1.24.1 `LICENSE` file.
- Also ships, under the same notice: ports of Go 1.24.1 standard library code, so the CLI matches the Go seed byte for byte. `src/core/shared/go-json.ts` follows `src/encoding/json` (`scanner.go`, `decode.go`, `encode.go`, `indent.go`, `fold.go`) and `src/unicode/utf8`; `rfc3339Offset` in `src/core/entities/consolidate.ts` follows `time.Parse` in `src/time/format.go` and `format_rfc3339.go`; `src/core/shared/go-os-error.ts` holds error text from the `src/syscall` errors tables; `src/core/shared/go-path.ts` follows `src/internal/filepathlite`.
- Also ships, under the same notice: Go's simple case-folding result for every non-ASCII rune whose fold is another rune (1,428 runes), in `src/core/shared/go-fold.ts`, used by `goFoldName` (`src/core/shared/go-json.ts`) to match JSON object keys to struct fields as `encoding/json` does. `scripts/generate-go-fold.ts` runs Go 1.24.1's `unicode.SimpleFold` (`src/unicode/letter.go`, with the case tables of `src/unicode/tables.go`, Unicode 15.0.0) through the `foldRune` of `src/encoding/json/fold.go`.
- Also ships, under the same notice (the intake port): ports of Go 1.24.1 `encoding/csv` (`reader.go`, `writer.go`) in `src/core/intake/convert/csv.ts`; `strconv.Unquote` in `src/core/intake/index/frontmatter.ts`; `strings.Fields`, `strings.EqualFold`, `strings.ToLower`, `path/filepath` `Rel`, `IsAbs`, and `Ext`, and `strconv.Atoi` in `src/core/intake/go-text.ts`; and the `flag` package's `PrintDefaults` text, now through the shared `src/cli/go-flagset.ts` (P4 and P5 merge). And a port of `html.Render` and its `escape` and `escapeComment` rules from `golang.org/x/net/html` v0.48.0 (`render.go`, `escape.go`), in `src/core/intake/convert/html.ts`. `golang.org/x/net` is published by the Go Authors under the same BSD-3-Clause license text as below. And a port of the `encoding/xml` decoder (`Decoder.Token`, `rawToken`, `text`, `name`, `nsname`, the XML name tables `first` and `second`, and `procInst` from `src/encoding/xml/xml.go`, and the root-element search of `Unmarshal` from `src/encoding/xml/read.go`), in `src/core/intake/convert/go-xml.ts`, which carries its own `@license BSD-3-Clause` header; and the first header checks of `pdf.NewReader`, listed in its own section below.
- Also ships, under the same notice (the discovery and design ports): ports of Go 1.24.1 standard library behavior for the discovery and design ports. `src/cli/go-flagset.ts` follows `src/flag/flag.go` (`FlagSet.Parse` with `ContinueOnError`, `failf`, `defaultUsage`, and `PrintDefaults`); `src/core/shared/go-text.ts` follows `filepath.Rel` and `IsAbs` (`src/path/filepath/path.go`, `path_windows.go`), `bufio.Scanner` with `ScanLines` (`src/bufio/scan.go`), `bytes.TrimSpace` and `strings.ToLower` (`src/bytes/bytes.go`, `src/strings/strings.go`), and `json.Marshal` (`src/encoding/json/encode.go`).
