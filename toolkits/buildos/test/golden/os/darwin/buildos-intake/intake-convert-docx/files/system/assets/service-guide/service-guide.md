# Sample Tool Library Service Guide

This guide describes how the sample tool library lends equipment to members. All names are invented.

# Opening Hours

The front desk opens at 09:00 and closes at 17:30. Weekend hours vary.

## Lending Steps

1. Check the member card.
1. Scan the tool tag.
  1. Confirm the return date with the member.
1. Record the loan.

## Safety Notes

- Wear eye protection near the saw bench.
  - Keep cords off the floor.
- **Report damaged tools at once**
  - Tag the tool as held.

## Tool Categories

| Category | Loan days | Deposit |
| --- | --- | --- |
| Hand tools | 7 | None |
| Power tools | 3 | Small \| refundable |
| Garden tools | 14 | None Seasonal only |

Questions go to the front desk team.
