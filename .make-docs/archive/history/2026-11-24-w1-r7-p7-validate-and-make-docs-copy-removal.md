# W1 R7 P7 Validate and Make Docs Copy Removal

## Changes

Runs P7 Stages 4 and 5 ahead of Stages 1 to 3, which wait on the owner's copy of the adopter skill files; this is a recorded departure from the default stage order. Adds `buildos validate` (`src/core/validate/`, `src/cli/commands/validate.ts`): a port of the legacy `validate_config.py` checks over installed paths, with the shared envelope, `--root` (default: the current folder), help, and exit codes 0, 2, 3, and 4. Adds 73 invented fixture cases, the legacy results captured once with Python 3.14.10 (`test/golden/validate/`, regenerated by `capture.ts` from git), and a parity test on (code, path, field, detail). 17 cases differ only as recorded divergences (PRD 13 rules from register D-004, D-006, and D-007, and safe input handling). Hostile-input tests cover oversized files, deep nesting, links out of the root, bytes that are not UTF-8, CRLF, and byte order marks. Deletes `system/.os/scripts/validate_config.py` and replaces every reference under `system/`; adoption leaves a Go-era copy in place. Deletes `system/docs/` and `system/.make-docs/`: all 70 files were Make Docs-owned, including `harness-capability-matrix.md`, which is byte for byte a Make Docs 2.0.9 resource, so nothing moved. Adds a link check over `system/` and `docs/prd/`. Local, on macOS: `npm test` 2,046 tests, 2,034 pass, 0 fail, 12 skipped; installed-tarball golden compare 167 of 167; pack 109 files. The Go golden check could not run (no Go on this machine), and the three-OS CI run is pending.

Framing: [W1 R7 backlog](../../../docs/work/2026-11-23-w1-r7-buildos-node-typescript-cli-rewrite/00-index.md), [P7 phase](../../../docs/work/2026-11-23-w1-r7-buildos-node-typescript-cli-rewrite/07-skills-and-validation.md), and the [evidence report](../../../docs/work/2026-11-23-w1-r7-buildos-node-typescript-cli-rewrite/evidence.md#p7-skills-and-validation).
