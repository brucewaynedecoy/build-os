# W1 R7 P9 Version 0.2.0 and the Release Runbook

The evidence lists every follow-up from F-P8-06 to F-P9-14 with its status and its place before or after the release, records that a staged npm version cannot be installed before approval (so the pre-approval smoke runs on the release tarball, and new follow-up F-P9-15 adds a tarball input to the smoke), and writes the `0.2.0` runbook, steps a to k, each with its commands and who does it. Nothing is published, and `release-candidates.json` is unchanged.
