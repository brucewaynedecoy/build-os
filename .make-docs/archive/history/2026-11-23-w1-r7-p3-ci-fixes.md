# W1 R7 P3 CI Fixes

## Changes

Fixes the test failures that CI run 45311343136 found for `f1755e5` (Linux 1 test, Windows 9 tests; macOS and OSV passed), with no production code change: the port matches Go in every case. On Linux, `pwd-through-symlink-dotdot` failed because the `{REAL}` and `{BASE}/work` placeholders had the same text, so `makePwdLayout` in `scripts/capture-pwd-goldens.ts` now makes `<base>` a symlink to a sibling folder; a recapture with the Go 1.24.1 seed is byte-identical. On Windows, `recoveryFor` in `test/entities-cli.test.ts` spells the root with `goQuote`, as Go's `%q` does; the EIO-on-sync test checks only the message prefix, because the port skips that folder sync on Windows (t14, PE-005); and the HTML-escape test uses a folder name that NTFS allows. Local, on macOS: `npm test` 1,120 pass, 0 fail, 4 skipped (Windows-only); `entities-bundle.test.ts` 22/22 also with `TMPDIR` on a symlink-free path; `capture.mjs --check` 158 cases; `--verify-artifact` passes for three sets. The CI rerun on Linux and Windows was pending at commit time.
